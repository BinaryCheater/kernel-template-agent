# First source pass: vLLM RMSNorm launch policy

**Scope.** Standalone FP16 rank-2 RMSNorm. Trace the choice of threads per row from the host dispatch to the output loop. Source: [pinned dispatch](https://github.com/vllm-project/vllm/blob/2eae56c4ba0cf12087fec035514eedede83c257d/csrc/layernorm_kernels.cu#L253-L275) and [kernel](https://github.com/vllm-project/vllm/blob/2eae56c4ba0cf12087fec035514eedede83c257d/csrc/layernorm_kernels.cu#L65-L92). Starting pool: eight seed Templates.

**Instance.** One block handles one row. For row length D, vector width V = gcd(8, D) in FP16. Each row has N = D/V vector positions. The host selects a thread cap of 1024 when batch-invariant launch is enabled or token count is below 256; otherwise it selects 256. Actual threads B = min(N, cap). Thread j visits output vector positions j, j+B, ... below N. The same B reaches the variance reduction as its valid thread count.

**Pool delta.** Record a source-backed launch policy and its binding to the row implementation. The two values 256 have different meanings: a token-count boundary and a thread cap. The source comment gives increased SM concurrency as the motivation for smaller blocks. It supplies no measured crossover or general legal range. Output tiling describes row ownership; reduction partition describes partial sums. Neither seed rule derives this launch policy. Keep it as an instance finding pending a second policy example that clarifies what should be abstracted. No new Template or proof outline in this pass.

**Review.** With D=8192, V=8 and N=1024. Changing token count from 255 to 256 changes B from 1024 to 256 in ordinary mode; each thread now visits four output vectors instead of one. Batch-invariant mode keeps B=1024. With D=1024, N=128 and both caps give B=128. A local enumeration checked exact-once output vector ownership for D in {1024, 8192, 8193} and each of the three launch cases. This checks the index arithmetic only. Alignment and the reduction implementation remain separate questions. No GPU timings were collected.
