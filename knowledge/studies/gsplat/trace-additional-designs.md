## Remaining representative families and bindings

- `PrimingChainEncoding.cuh:14-190`, `ParallelBatchFwd.cu:520-564,675-696`: `monotone_prefix_bound_hint@1` binds upward fp16 rounding, saturation-priority bit, bounded negative next-batch index and atomicMin. Reader ignores K>b and falls back to1; no waiting CTA dependency. Packed relaxed atomics publish no unrelated payload. Initial K=0 can win equal-U ties, only losing optimization.
- `RasterizeCSR.cuh:25-145`: state SOA `[batch][1+channels+optional_normals3][pixel]`, pixel fastest. `record_field_axis_storage@1` binds axis_order=field_major, N=pixels, D=1+channels+optional_normals3. `physical_storage@1` supplies occupancy/lifetime only; count/scan constructs tile batches and round-major launch permutation preserves a bijection to tile-major storage. `ParallelBatchBwd.cu:510-590` seeds a batch with its cumulative end T and suffix dot(finalColor-boundaryColor,g); uses c_stop terminal checkpoint and skips later batches. `reverse_transmittance_replay@1` per batch plus additive gradient combination; all scan/replay writes precede backward.
- `2DGSSerialBatchFwd.cu:411-438`: `ordered_pair_distance_prefix_moments@1` stores prefix weight and weight*depth. Absolute-distance interpretation additionally requires sorted evaluated depths, not merely sorted Gaussian center keys. Median source means last accepted contributor with T_before>.5 (not a normalized conditional median). `2DGSSerialBatchBwd.cu:341-399,515-579` replays selected minimum-support branch, chooses 3D branch at equality, propagates distortion moments and saved median ID; cap derivative guard retained.
- `IntersectTileLidar.cu:235-385`: angular CDF maps dense half-open elevation endpoints using max-1 then +1. Seam A/B azimuth ranges merge; periodic range width capped at number of bins and emitted modulo bin count, preventing duplicate tiles. Nonperiodic overlapping A/B merge to full FOV. This supplies a different overlap predicate for `counted_overlap_depth_binning@1`; count and emit use identical merged ranges. Radial LiDAR depth is distinct from signed camera z.
- `RasterizeContributingGaussianIds.cu:42-140`, `RasterizeNumContributingGaussians.cu:45-125`: same accepted-hit callback supplies count, alpha and first-K bounded IDs/weights. IDs continue T updates even after output capacity reached. `TopContributingGaussianIds.cu:35-168` instead retains largest radiance weights then sorts those by depth. These are three declared output contracts, not equivalent storage changes. `RasterizeToIndices3DGSSerialBatch.cu:95-203` two-pass count/emit of pixel-Gaussian occurrences with supplied transmittance and candidate-range bounds; `counted_overlap_depth_binning@1` prefix reservation portion reused, without its tile-depth key stage. The workload's recurrence must be identical across count and emit. 2D indices substitutes surface support.
- `SparseTileLayout.cu:33-66,132-183`, `RasterizeToPixelsSparseFwd.cu:140-190`: `occupancy_bit_rank_addressing@1`; exclusive active tile writer, sorted packed pixel map, selected active tile's compact offset range. Sparse backward uses same bit-rank map. Inspected build wrappers do not establish unique input coordinates; bind only with caller uniqueness or preprocessing. Duplicates are an explicit unsupported binding rather than silently collapsed occurrences.
- `SphericalHarmonicsCUDA.cu:45-155` evaluates degree0..4 explicit normalized-direction basis, FP32 opmath for reduced-precision coefficients. `SphericalHarmonicsL1PlusCUDA.cu:665-770` changes ownership to coefficient-row/channel, reduces all dense batch-camera images into degree-sized register array, casts once; packed rows see one output. This binds `reduction_partition@1` result owner and local reduction plus `output_tiling@2` row/channel assignment; earlier atomic scatter ownership is an alternative with changed grouping. Degree specialization sizes MAX_K=(degree+1)^2-1 and zeroes padded coefficient tail. L1+ excludes DC. `SphericalHarmonicsViewDirectionCUDA.cu:38-145` precomputes camera offsets, reduces direction VJP per view with CUB256 and eight-item tiles; system atomic publication selected only for cross-device ownership. Nonzero normalization direction required; no claim of equal bitwise FP16 association.
- `QuatScaleToCovarCUDA.cu:35-115`: one Gaussian per thread computes covariance and/or precision from quaternion/scale; writes symmetric upper6 or rowmajor9, correcting GLM column indexing. `symmetric_matrix_packing@1` binds dimension3, upper6=(00,01,02,11,12,22); full index3*i+j=matrix[j][i]. `physical_storage@1` supplies capacity/lifetime, not this coordinate map. Precision requires nonzero scales; no choice of approximation hidden in layout.
- `../include/Cameras.cuh:432-487,1157-1215,1635-1708`: forward distortion precedes projection; inverse distortion follows camera unprojection. OpenCV Newton uses residual/Jacobian, determinant and update cutoffs; nonconvergence invalidates ray. FTheta polynomial inverse has its own fixed-iteration/convergence policy and ignores its convergence flag as commented source numerical convention; no universal convergence guarantee. Perfect pinhole/ortho and distorted camera models define separate workload maps. `../include/ExternalDistortion.cuh:50-115,165-225` triangular polynomial groups padded to MAX_ORDER5; nested Horner, asin input clamp, forward/inverse supplied coefficients. Fixed mathematical map under `output_tiling@2`, not free camera-model optimizer choice; inverse polynomial accuracy is caller model contract.
- `IntersectTile.cu:670-922`: disjoint global (image,tile) key intervals per device, local counts+prefix, host waits totals then concatenates disjoint sorted slices. Source uses system atomicAdd for shared per-Gaussian counts and merge_streams before consumers. Binds binning reservation plus `output_tiling@2` partitioned key domain; managed/accessibility/coherence is a required PrivateUse1 runtime premise, not assumed ordinary device pointer portability. `DistributedCollectives.cpp:50-90` delegates all-gather/all-to-all to Torch functional autograd collectives and wait_tensor; no local transport implementation to extract.
- `ProjectionEWASimple.cu:35-105` is camera-space input subset of EWA J-covariance-J^T, `Projection2DGSPacked.cu` uses same count/prefix/complete-record organization as packed3D with surface transform payload; these introduce no independent scheduling mechanism. `NullCUDA.cu:30-75` is a256-thread identity copy, `output_tiling@2` only. Camera wrappers expose mathematical camera helpers for testing, not a separate production pipeline.

## Pool boundary comparison

Read `mamba/ordered_affine_prefix@1`: its coordinatewise state has no triangular T-to-color coupling. Compositing summaries require C+=T*C_batch, so the new `ordered_transmittance_batch_summary@1` supplies this missing action and threshold replay. Read `flashinfer/stable_sparse_support_compaction@1`: stable occurrence rank is shared, but its fixed-capacity prepared support-row mode does not bind re-evaluated geometric predicate, block-prefix allocation or complete projection payload. The local compaction candidate makes that two-pass contract explicit; coordinator may consolidate this common rank algebra. Read `tiny-cuda-nn/selective_parameter_state_update@1`; local @2 adds only the explicit clockless transition domain, preserving @1 and its fields/obligations as documented in migration.md.

Final reuse audit: read DeepGEMM tensor_axis_permutation@1; it changes a rank3 view without movement and cannot express a newly materialized record/field storage order or symmetric triangular quotient. The two local layout candidates supply those missing maps. QuatScaleToCovarCUDA.cu:205-285 confirms half off-diagonal symmetric gradient representative for packed covariance/precision.
