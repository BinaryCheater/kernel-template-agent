Source: python/sglang/kernels/jit/csrc/attention/kda_prefill.cu in the retained pinned superproject. CUDA C++, SM100a/103a only; chunk BT64, K=V128. No timings are reproduced.

## Concrete selected path

For an equal-length long sequence with enough chunks, `pick_route`:3289–3320 compares analytical builder and chain wall models, including jobs per SM, piece budgets and source-fitted constants. Fused route creates two disjoint grid regions: NP*H builders first and NP*H trailing chain blocks. Builders transform local chunks, build affine maps and release-publish one flag per piece/head after global/TMA proxy fence. A chain block waits acquire on preceding piece flags and its own factors; prefix state reconstructed from maps lets the block process only its local piece. A short NP1 case uses two kernels and no piece maps. Ragged route uses a per-sequence piece table; chunk, piece and state origins retain sequence identity.

## RHS solve delta and affine premise recovery

blocked_unit_lower_rhs_solve@1 now captures the missing completed-RHS-block object. Bind order64,block_order16,rhs_columns256. Source1044–1107: off-diagonal products subtract from sU, then each tid<256 owns one RHS column and performs16-row FP32 forward substitution. Afterward packed transposed high/low copies feed later blocks. P stores the negated first128 RHS columns as BF16; u0 stores second128 as FP32. The omitted low*low term is part of numerical policy, not exact algebra. checks/triangular_rhs.json verifies a64x3 exact-rational instance; native approximation remains open. A full inverse is not materialized, so blocked_unit_lower_inverse@1 is a comparison rather than a direct binding.

The affine state premise is recoverable from the one-token delta rule, not inferred merely from names: for stateS[V,K], per-K decayD, key columnk, value columnv and scalarbeta, S'=SD+beta*(v-SDk)*k^T = S*D*(I-beta*k*k^T)+beta*v*k^T. Thus every token is right-affine, and an ordered64-token chunk remains right-affine. The chunk's triangular solve eliminates causal prediction feedback to build compact factors; changing solve precision changes the resulting approximateL,c. Feature-dependentD means chunked_decayed_outer_product_state@1's scalar-decay premise is false. That existing rule must not be used to certify this KDA factorization.
