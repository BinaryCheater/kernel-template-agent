# Speculative navigation representative pass

Status: active. Paths are relative to pinned source `python/sglang/`, not this study. Concrete body bindings and proposed missing rules are recorded below. No GPU check.

## EAGLE tree construction and greedy verification

`kernels/jit/csrc/speculative/tree.cuh` dispatches to local bodies in `kernels/jit/include/sgl_kernel/speculative/eagle.cuh:36-290`; these are not absent dependency implementations. One CTA/request and one thread/node build the masks and positions; draft nodes<=1024, packed mask nodes<=32. Parent lookup follows selected candidate identity through `selected_index/topk` and `parent_list`; selected nodes must contain all their ancestors and the parent chain must terminate at the root. Malformed-parent warning/fallback does not establish that contract for arbitrary input.

Each nonroot node independently follows ancestors, setting its own row's self/ancestor bits. Root is visible to every draft node; position=verified_prefix_length+depth. Full mode prepends all verified prefix columns and stores one byte per visibility value; qlen-only stores just the NxN tree visibility. Packed mode stores row bits little-endian, physical row width8/16/32 according to N<=8/16/32. `bitstream_packing@2` is a provisional reuse lead with code_bits=1,word_bits=8,p.length=rounded_row_bits,p.min_code=0,p.max_code=1: padded bits remain zero and one thread owns all bytes of one row. The source's per-row ownership is distinct from the rule's original complete32-code wording; proposed@3 and its migration below make that partition explicit.

The packed body only assigns byte0=1, then ORs ancestry bits, so zero initialization of the other bytes is necessary. `srt/speculative/eagle_utils.py:175-260` proves the caller does this: reused packed masks fill0, new packed masks use zeros. Retrieval links start-1 in all modes. Full mask prefix fill can be skipped only when no consumer reads those columns; the device body still writes every tree cell. This is an actual read-domain premise, not a general memset-elision claim.

Thread0 separately builds first-child/next-sibling navigation links by visiting selected nodes in reverse, prepending each child. As a result siblings are traversed by increasing selected slot. `retrieve_index` maps local slot to flattened batch/node identity; links remain local slots. These different index spaces must not be conflated. The root has slot0; parent IDs resolve by full selected-ID search.

`VerifyTreeGreedy` runs one thread/request. Starting at root, inspect children/siblings until a candidate token equals the target prediction of the last accepted node. Accept its flattened retrieval ID and continue from that child. Stop when no child matches or output capacity is reached, then emit exactly one target bonus at the last accepted node. Targets must be evaluated at the same ancestor history encoded by the mask; arbitrary per-node predictions are not interchangeable. Duplicate matching children use the first linked match and require caller-defined equivalent histories if they represent the same token. This is deterministic greedy verification, not draft/target probability-ratio correction.

Resident traversal and exact tree views are extracted below; matrix-solve-only `iterative_state_residency@1` was deliberately revised rather than silently stretched.

## DFlash contiguous chain and lattice selector

`kernels/ops/speculative/dflash.py:8-63,251-347` supplies concrete Triton bodies. The contiguous chain path compares shifted draft candidates to per-position target top1. The original fused body carries a scalar prefix_live flag through the comparison loop. The newer `_fused_correct_drafts_and_bonus_kernel` computes the first mismatch by a minimum over all independent match lanes, with padded/all-match lanes resolving to block_size-1. That equivalence depends on taking the leading prefix, not counting every later match. Bonus is target[accept_len]; commit_len=accept_len+1. Only this committed prefix is live: the fused output buffer may retain unaccepted draft values beyond commit_len, so consumers must respect the length rather than assume an invalid-filled tail.

`_selector_walk_kernel` is one warp/request and a loop over slots, with previous candidate index resident in registers. It loads scores[row,slot,previous,:], chooses current index, saves the entire proposal probability row Q and emitted token, then sets previous=index. Greedy rows select the first NaN if present, otherwise the first maximum, and write a point-mass Q. Sampling rows divide scores by the request temperature, use stable softmax, then select sum(uniform>=CDF) clamped to K-1. Uniform identity is row/slot, unchanged by moving the walk into one kernel. The wrapper uses contiguous score/candidate/uniform inputs and one warp. `lilicorr.py` constructs the first-slot score broadcast and subsequent pair-score lattice, and preserves Q rows for later correction. Source launch and caller cap the fused candidate head at16.

The first-failure and resident-state choices are captured below. Temperature positivity, finite stochastic scores and CDF rounding/fallback are numerical workload premises; NaN handling of the explicit greedy branch is different and cannot be erased.

## Extracted navigation composition

- `iterative_state_residency@2` deliberately extends@1's bounded-solve scope to dependent finite-state walks and preserves a required per-step output tape. DFlash binds state_site=registers,output_retention=per_step, one warp/request, complete mutable previous index plus current K-vector workspace. Immutable score rows stream from global storage; the Q and token tape stays global and has no reader until completion. EAGLE binds the same output mode with one thread/request, current child/sibling slot and last accepted flattened ID. All old matrix-solve bindings map to final_only; [migration](delta/iterative_state_residency@2/migration.md) preserves their fields and obligations.
- `first_failure_prefix@1`, strategy=parallel_first_false, recovers DFlash's length=block_size-1 first-mismatch result; the older loop binds serial_live_prefix. Bonus target[result] and commit_len=result+1 are dependent consumers with an available boundary record. Counting all matches would violate the rule.
- `tree_navigation_materialization@1`: EAGLE input_view=parent_indices,output_view=both; ngram input_view=ancestor_rows,output_view=child_sibling. Native candidate IDs resolve to topological local parents; flattened retrieval IDs remain a separate map. `ngram.cuh:26-105` finds the greatest preceding ancestor as parent, earliest later descendant as first child, and the next node whose immediate parent matches as sibling. These identities require a rooted, topological, ancestor-closed tree, not an arbitrary graph mask.
- Proposed `bitstream_packing@3` retains the@2 bit mapping but makes exclusive whole-container ownership explicit instead of assuming every writer owns32 logical codes. Packed EAGLE binds code_bits1,word_bits8,ownership_unit=whole_containers,p.length8/16/32; every padded row has one node-thread owner and initialization is visible before OR. Full32-code source instances remain available under complete32_codes. [Migration](delta/bitstream_packing@3/migration.md) separates this ownership clarification from the unchanged coordinate proof.

`checks/navigation.py` / `.json` enumerates boolean rows through length12 and rooted topological trees through8 nodes, reconstructs parent/child/sibling views, checks byte/bit round-trips with zero padding and checks resident finite-state output tapes. This validates the structural transformations; native synchronization and floating-point selector behavior remain their named obligations.

## DSpark split sampling and residual representation

`kernels/ops/speculative/dspark/markov_sample.py:35-165,189-238` is a distinct distributed large-vocabulary selector. Each1024-value block adds optional bias in FP32, explicitly rounds to FP32/BF16/FP16 step dtype and optionally stores those logits. A temperature-zero row uses greedy first-NaN/first-max selection. A positive-temperature row derives10-round Philox words from global vocabulary quad,request row,step,offset, then computes value/temperature-log(-log1p(-u)). Interleaving maps four words to consecutive original token IDs. One FP32 score plus bitcast int32 index is published per part; finish reduces every rank/part and resolves ties by smallest original ID, preserving first-NaN policy. The transport's signed-zero sentinel can change bitcast ID0, so the consumer explicitly clears the sign bit. That codec is a communication-realization obligation, not a new random selector identity.

`keyed_weighted_race_selection@2` binds split_width1024,key_mode=single,score_form=log_weight_gumbel,uniform_map=complement_midpoint for this stochastic path. Its immutable log weight is the rounded biased step value divided by temperature. The exact score is a monotone transform of log(U)/weight and needs no explicit normalized softmax. `VOCAB_START` must be4-aligned for the source's quad/word mapping to preserve original token identity across ranks; input partition alignment is a premise, not an asserted arbitrary-origin property. FP32 u may round to1, producing an infinite exponential and negative-infinite score; generator endpoints/ranks follow the selected native policy. Actual Philox quality or an exact continuous categorical law is not proved here.

`blockwise_rejection.py:122-397,408-491` splits correction into full-vocabulary stats, serial chain acceptance, tiled residual race and final insert. Target/draft LSE combines max-rescaled partial sums from every block. Acceptance is log_p>log(u)+log_q until the first rejection, with actual positive draft support and matched histories required. This reuses `draft_target_residual_correction@1`, diagnostic_mode=none, with an admitted log-acceptance/CDF-alternative realization; its native endpoint and zero-residual obligations remain. Bonus rows skip stats because raw target logits suffice for the final log-weight race.

General draft correction keeps `max(P-Q,0)` in log encoding: logP+log1p(-exp(logQ-logP)) when P>Q, else-inf. `positive_difference_log_encoding@1`, encoding=log, supplies that representation choice; the classic chain body binds linear. One-hot draft correction simply masks out the rejected token. Normalization can be omitted for a log-weight race invariant to a common additive shift. A ratio rounded to1 can erase a tiny positive residual; the host boundary witness records this concrete numerical premise instead of calling the source formula universally support-preserving. Murmur keyed per-coordinate race uses the same requested score/ID reduction contract with its own native random-map policy; no unverified cross-generator identity is assumed.

An optional verification budget truncates the raw accepted prefix. If capped<raw, bonus is the next already accepted draft, rather than the correction drawn for the later raw rejection; trim=raw-capped. This is a prefix cut of the same verified continuation, not acceptance of later independent matches. The call still advances the noise counter once, after prior kernels have read it under stream order. `stage_commit.py:12-68` copies locations/positions/optional state slots for staged rows and zeros commit lengths beyond active requests; stale metadata outside a zero length is not published as live KV.

`checks/log_race.py` / `.json` checks exact scalar score correspondence, aligned quad/word coordinates, residual encoding and a near-equal FP32 ratio counterexample. It does not certify native transcendental ranks, transport sentinel coding or a probability law.

## Target-only stochastic tree and other navigation realizations

`jit/include/sgl_kernel/speculative/sampling.cuh:39-209` is a local adaptation around dependency CUB/sampling primitives, not a call to the classic draft/target chain rule. It traverses ordered siblings with one shared test coin and accumulates each candidate's target probability; acceptance moves to that child's history and fresh coin. Rejected candidate masses are recorded in `draft_probs` scratch, and the final full-vocabulary two-pass sampler uses positive target-minus-that-exclusion mass. `srt/speculative/eagle_utils.py:808-846` supplies zeros_like(target_probs) when ordinary target-only verification is selected; actual draft probabilities are passed only for the separately dispatched rejection sampler.

`enumerated_target_mass_sampling@1`, selection=candidate_intervals_then_residual, binds the exact target-law subcase threshold_acc=1,threshold_single=1 with distinct sibling token IDs. The host launcher also accepts other thresholds; these are workload changes, not bindings of this exact-law rule. Fresh exclusions, complete residual support and independent final uniform are explicit premises. Source vector-load alignment/tail and uniform-control stores need their native realization admission; host mass partition checks do not establish it. `checks/enumerated_mass.json` checks exact rational normalized rows and every ordered distinct candidate subset through vocabulary4.

`ops/speculative/spec_tree.py:211-317` implements the same greedy child/sibling walk in Triton with bounded predicate loops and safe-index loads. Target prediction is invariant within one sibling search and loaded once per level. It reuses `iterative_state_residency@2`, state_site=registers,output_retention=per_step, with unchanged tree history and flattened-ID mapping; its bounded empty-sibling path cannot extend the accepted prefix. The CUDA one-thread and Triton predicate-loop forms differ in execution mapping, not the tree invariant.

`ops/speculative/reconstruct_tree.py:57-115` materializes an entire padded NxN ancestor mask in one program, then computes depth (row sum), parent (row max ancestor index), first child (column min descendant index), and next sibling (min later index sharing parent). It reuses `tree_navigation_materialization@1`, input_view=ancestor_rows,output_view=child_sibling. `physical_storage@1` level=reg,buffer=dedicated,share_order=none describes the retained mask/depth/parent values, subject to actual compiler capacity and spill behavior. This is a parallel reduction realization of the same topology transform as ngram's scalar per-node scans; no performance result is inferred.

`ops/speculative/uno_tree.py:254-383` has a workload-defined deterministic best-first recurrence over candidate edges: compare path log mass, then shallower depth, smaller rank/token/parent. Q-1 node expansions are prescribed, not a freely interchangeable verification strategy. Each expansion examines Q*K candidate slots, chooses one unused valid edge, writes its EAGLE parent-edge encoding and updates depth/log mass. `physical_storage@1` binds used-edge mask to level=reg,buffer=dedicated,share_order=none; search_depths/search_log_masses to level=gmem,dedicated,none, with each update followed by a local debug barrier before subsequent reads. Complete state is partly global, so this is not claimed as a literal binding of all-state-on-chip `iterative_state_residency@2`. Edge value/identity reductions are part of this fixed recurrence; no cross-lane lowering is asserted without a concrete lane map. Output tuple stores are fused into the same producer iteration, retaining their original graph identities.

`ragged_verify_kernels.py:89-110,168-183` prepares graph-capacity metadata: preserve actual verify lengths, distribute leftover capacity evenly across dummy rows (remainder to earlier dummy rows), or append it to the last real physical row if no dummy row exists. Validity still comes from original logical lengths. Inclusive length sum supplies qo_indptr; exclusive sum supplies extend starts. This fixed metadata computation is not a semantic license to verify padded tokens. Output points and buffers bind `output_tiling@2` (one program owns the complete short metadata row) and `physical_storage@1` (global dedicated metadata); no alternative scan lowering or new bucket policy is claimed. KV stage/commit lifetime is reviewed with the cache-publication family.

`dspark_accept.py:350-415` uses a different small-workspace softmax realization:4096-wide loops make three input passes for row max, exponential sum, then normalized output. Apply `statistic_dependent_rematerialization@1`, retention=recompute, twice: first pure transform z=x/temperature across the max join; then e=exp(z-max) across the sum join. Inputs/temperature remain immutable through the third pass, and output is a separate allocation. This trades resident full-vocabulary values for repeated reads; full row domains and transform recipes are unchanged. Nonfinite rows/temperature need their ordinary numeric policy, so this is not a universal finite-output claim.

The remaining DSpark accept helpers (`dspark_accept.py:205-238,521-585,654-700,760-879`) gather the selected bonus, choose already-computed greedy versus stochastic result tuples, cap accepted length and finalize commit/new sequence lengths. For their256-request pointwise kernels, `output_tiling@2` binds tile_m256,tile_n1,executor=cta,index_map=identity with tail masks; separate global output buffers bind `physical_storage@1`,level=gmem,buffer=dedicated,share_order=none. Short prefix-metadata preparation has one CTA for the whole batch; a representative batch32 binds tile_m32,tile_n1,executor=cta,index_map=identity, with all prefix inputs available to that CTA. These helper branches do not change the proposal, target law or prefix invariant. `verify_sampling.py` resolves CUDA to the local chain and local tree kernels already traced; NPU/MUSA fallback branches are excluded.
