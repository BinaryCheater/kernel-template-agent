Composition example: bounded chunk descriptors produce LAMB update→per-tensor norm reduction→global tensor id lookup→trust-ratio update. Synchronization between stages and preserved global identity are required even if every per-chunk pointer is correct.

Optimizer variant reconciliation: csrc/multi_tensor_adagrad.cu:63–70 updates accumulated square h using decay-adjusted gradient for coupled L2, or raw gradient with decay added to final update for decoupled mode. csrc/multi_tensor_sgd_kernel.cu:18–34,87–96 owns first-run momentum initialization, dampening, Nesterov and decay-before/after-momentum; skip flag is a whole-chunk guard. csrc/multi_tensor_novograd.cu:74–88,121–136 first updates one norm per tensor (L2 sqrt(beta2*old²+(1-beta2)*new²), or L∞ blended norm), then normalizes before or after momentum according to moment_mode. These distinct numeric algorithms share bounded_chunk_launch_table@1, not one optimizer formula. Global tensor identity selects norm metadata after launch rebasing.

Indexed-map realization: index_mul_2d_cuda_kernel.cu:15–26,74–91 maps idx1[row]*64+feature to source, vectorizes4 features, atomically adds grad_out*in2 to each indexed input1 feature, directly writes grad_out*in1 to unique input2 row. indexed_additive_scatter@1 vector_width=scalar for FP32 atomic adds (four scalar calls, not a vector-atomic transaction); half accumulation requires its own dtype realization beyond that candidate's FP32 scope. Rotary device path is in fused_rotary_positional_embedding.h:24–47, not only the .cu launcher: split-half pair d↔(d+d2/2)%d2 with negative second-half contribution for first-half output; tail d>=d2 copies input. Cached-cos/sin variant avoids trig evaluation, preserving same pair identity.

The focal-loss gradient checkpoint choice is captured by deferred_gradient_scalar@1, including the required numeric admission and normalizer lifetime; a source motivation about small gradients is not an error bound.
