No equal-count rank stride is inferred. This adds a variable-work scheduling instance, not a new numerical operation.
- `sendrecv.h:15-180`: channels get disjoint ncclP2pPartBounds byte intervals, send/recv activity masks built by one warp. ## Final core reconciliation

`all_gather.h:120-210`, `collectives.h:810-945`, `prims_simple.h:1270-1398` establish PAT AG counterpart: dimension peers reverse RS direction, first visit copies to local output, later accSize suppresses duplicate output writes, sends/receives retain descriptor offsets and post flags; hierarchical AG broadcasts then gathers local NVLS rank order. Full PAT schedule is an explicitly source-bound algorithm with phase/skip tables; bounded descriptor handoff does not imply its mathematical routing proof. `all_gather.h:274-370,455-530`, `reduce_scatter.h:444-515` add rail-wise denseToUserRank permutation, clip intervals at node/rank boundaries and preserve byte versus element units. These are hierarchy/map realizations, not rank-contiguous assumptions.

`generate.py:128-182` restricts LL/LL128 to ring/tree, NVLS op/type menu, CUDA/architecture gates and signed→unsigned equivalent modulo arithmetic. Generic entrypoint specialization can differ from dynamically dispatched actual function: kernel name alone does not identify executed algorithm. Generated specialized/profiler variants retain algorithm barrier compatibility. Tests, examples and contrib benchmarks instantiate these mechanisms; wrapper build files do not establish device behavior without the representative bodies cited above.

Coverage is now reconciled against core device generators, symmetric generators, public device primitive implementations and bundled contrib families. Source mathematical and native memory premises remain proof obligations. No major source design family is left at a directory-only disposition.
